# Validation — 0.1.2

Ian requested removal of continuation indicators from all titles, including embedded audio tags, and strict taper-style preservation with no upsampling or downsampling.

Title cleanup applies to TXT-derived names, embedded TITLE fallback, filename fallback, manually edited names at export, and displayed chapters of existing MKAs. Trailing/leading `>`, `->`, `-->`, `=>` and Unicode arrows are removed. Internal medley arrows become a slash. Song punctuation such as the apostrophe in He's Gone and the hyphen in Brown-Eyed Women remains. Original source tags and the verbatim TXT attachment are unchanged.

The core now carries source bit depth, sample format and channel layout through protobuf to the inspector. Packaging rejects mismatched audio formats rather than adapting them. It re-probes each source before invoking FFmpeg, disables automatic conversion filters, stops on decoding errors, and in supported FLAC mode sets the original rate/depth explicitly. A temporary output with a different rate/depth/channel count is refused before publication. Stream copy remains the default. FLAC conversion is restricted to supported lossless 16-/24-bit integer input; other formats can use stream copy.

Managed/native verification exercises stream-copy and FLAC output at 44,100 Hz/16 bit, 48,000 Hz/24 bit and 96,000 Hz/24 bit. The 24-bit fixtures contain nonzero precision below 16 bits. At every rate/depth, output metadata preserves the original format and decoded 32-bit PCM bytes equal the exact concatenation of the source samples, including fractional-duration track joins. This checks for sample loss, duplication, inserted silence, precision loss, dithering or fades. The original TXT attachment is also checked byte for byte. A real folder of mixed 44.1/16 and 96/24 files is refused. Altered review metadata claiming a different rate is refused after probing the real source. Existing playback/resume checks remain.

The preservation rule concerns the files created by Show Player. Windows/audio-device playback conversions are outside this export guarantee. Existing source silence is retained; no silence removal, crossfade, gain change or added gap is performed.

The normal release pipeline passed formatting, Clippy with warnings denied, 22 domain tests and 3 ABI tests, the expanded managed/native preservation suite and the torrent/webseed check. WinUI release/style checks passed. The 0.1.2 installer upgraded the existing per-user installation with exit code 0; saved settings and playback database hashes were unchanged. The installed version launches through the existing Start Menu shortcut. The actual Winterland inspector check confirms 22 clean song titles, 12 Set 1 / 10 Set 2, 44,100 Hz and 16-bit for every track, and zero remaining arrow titles.
